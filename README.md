# Le Fournil - Boulangerie Artisanale

Bienvenue sur le dépôt du site vitrine de **Le Fournil**, une boulangerie artisanale traditionnelle.

## 🥖 Présentation du projet

Ce projet est un site web statique multi-pages conçu en HTML5 et CSS3. Il présente les produits, les tarifs, le savoir-faire ainsi qu'un formulaire de contact pour une boulangerie artisanale.

### Pages du site :
- **Accueil (`index.html`)** : Présentation du savoir-faire, produits phares, tableau de commande/tarifs et galerie photo.
- **La Carte (`carte.html`)** : Découverte détaillée des différents pains et gâteaux.
- **Contact (`contact.html`)** : Formulaire de prise de contact et horaires d'ouverture.

---

## 🛠️ Technologies utilisées

- **HTML5** : Balisage sémantique moderne (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, `<figure>`).
- **CSS3** : Variables CSS (`:root`), Flexbox, CSS Grid et mise en page responsive.
- **Google Fonts** : Police Roboto.

---

## 🚀 Comment lancer le projet

1. Clonez ce dépôt ou téléchargez les fichiers :
   ```bash
   git clone https://github.com/david4553/mon-premier-d-p-t.git
   ```
2. Ouvrez simplement le fichier `index.html` dans votre navigateur web préféré (Chrome, Firefox, Edge, Safari) ou utilisez l'extension *Live Server* dans VS Code.
